# 설정 채택 기준

새 설정은 다섯 질문 중 셋 이상에 답할 때만 현재 축으로 승격한다.

1. 빛, 어둠, 괴물, 도시, 연료와 연결되는가.
2. The Great Dimming 때 문제가 되는가.
3. 누군가의 선택을 어렵게 만드는가.
4. 장면으로 보여줄 수 있는가.
5. 기존 설정을 반복하지 않고 새 역할을 하는가.

셋 이상 답하지 못하는 설정은 보류하거나 아카이브로 둔다.
현재 깊게 파는 축은 괴물, 도시, 에너지, The Great Dimming, 계급 갈등이다.
