# 캐릭터 확장 프롬프트

당신의 임무는 원본 메모와 기존 설정을 바탕으로 캐릭터 문서의 **초안**을 확장하는 것이다.

이 작업은 **draft 생성 단계**다. `raw/`는 공개 문서가 아니므로, 원문을 그대로 위키 문서로 바꾸지 말고 `drafts/characters/`에 둘 후보 초안으로 정리하라. 공개용 `content/`, 즉 현재 저장소의 `contents/` 문서로는 확정하지 말 것.
이 문서에서 `content/`는 README의 개념적 표기이며, 현재 저장소의 Quartz 공개 입력은 `contents/`다.

## 입력

다음 입력을 기준으로 작업한다.

- 캐릭터 관련 raw 메모: `{{raw_notes}}`
- 이미 존재하는 관련 문서: `{{related_content_docs}}`
- 이번에 보존해야 할 설정: `{{must_keep}}`
- 이번에 비워 두어도 되는 불확실 정보: `{{unknowns_allowed}}`

## 참조 규칙

1. `schema/entity-schema.md`를 우선 준수한다.
2. 파일명과 `slug`는 영어 kebab-case만 사용한다.
3. `title`은 한국어 표시명을 허용하지만, 본문과 frontmatter는 일관되게 유지한다.
4. 관계, 소속, 생몰년, 사건 연표는 근거가 있을 때만 적는다.
5. 확인되지 않은 항목은 억지로 채우지 말고 `미상`, `추정`, `검토 필요`로 남긴다.

## 작업 절차

1. 캐릭터의 핵심 정체성을 한 문장으로 정리한다.
2. raw와 기존 문서를 대조해 이미 확정된 사실과 새로 확장할 사실을 분리한다.
3. 캐릭터의 기본 정보, 외형, 성격, 배경, 능력, 관계, 주요 사건을 구조화한다.
4. 시간 정보는 `schema/timeline-rules.md` 형식에 맞춰 적는다.
5. 관계 정보는 가능한 한 구조화된 참조로 쓴다.
6. 중복되거나 충돌하는 설정이 있으면 하나를 고르기보다 차이를 설명한다.
7. 최종 결과는 초안 문서와 검토 메모가 분리되도록 작성한다.

## 출력 형식

한국어로 아래 순서를 지켜 출력한다.

### 1. 초안 문서

다음 형식을 따르는 마크다운 초안을 작성한다.

```md
---
title: ...
type: character
slug: ...
aliases:
  - ...
tags:
  - ...
status: draft
created_at: YYYY-MM-DD
updated_at: YYYY-MM-DD
---

# ...
```

본문은 다음 섹션을 우선 포함한다.

- 요약
- 기본 정보
- 배경
- 성격
- 외형
- 능력 또는 역할
- 관계
- 주요 연표
- 검토 필요 항목

### 2. 검토 메모

초안 뒤에 짧게 덧붙인다.

- 새로 확장한 설정
- raw에서만 확인된 정보
- 아직 불확실한 정보
- 사람이 다시 확인해야 할 부분

### 3. 금지 사항

다음은 하지 말 것.

- 근거 없는 성격 단정
- 없는 사건의 추가
- 관계의 대칭성 임의 생성
- 연도나 나이의 무근거 추정
- raw 내용을 공개 문체로 그대로 복붙하는 행위
