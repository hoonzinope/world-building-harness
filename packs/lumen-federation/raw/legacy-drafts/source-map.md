# 루멘 연방 작업 노트

이 문서는 공개 첫 진입로가 아니라 설정 정리용 작업 노트다.
루멘 연방의 공개 중심은 불빛, 어둠, 도시, 괴물이며, 아래 항목은 이전 설정을 현재 구조 안에서 어디에 배치할지 확인하기 위한 매핑이다.

## 중심 은유

이전 중심축은 기록, 정산, 공명, 인간성 지분이었다.
현재 중심축은 불빛, 어둠, 도시, 괴물이다.
따라서 추상 제도는 먼저 설명하지 않고, 소등 명령 아래에서 누가 빛을 배정받고 누가 어둠으로 밀리는지 보여 주는 장면으로 낮춘다.

## 도시 매핑

- 성운시, 수도, 공보 기능은 [Aurel / 오렐](cities/aurel.md)로 흡수한다.
- 낙원시, 전선, 피난 기능은 [Noxmere / 녹스미어](cities/noxmere.md)와 [Edenfall / 에덴폴](cities/edenfall.md)로 나눈다.
- 구천, 화령, 공업, 사체 처리, 에너지 기능은 [Cindral / 신드랄](cities/cindral.md)로 묶는다.
- 세광, 약, 보험, 감정, 수면 기능은 [Lucera / 루세라](cities/lucera.md)로 묶는다.
- 진평, 법적 인간성, 시민권, 출입 허가 기능은 [Iustar / 유스타르](cities/iustar.md)로 묶는다.
- 웅천, 안남, 암시장, 세탁, 도박 기능은 [Veyr / 베이르](cities/veyr.md)로 묶는다.
- 무진, 경계, 피난, 외곽 권역 기능은 녹스미어 주변 권역으로 둔다.

## 제도 매핑

- 문명 공명압은 [괴물 유인 신호](systems/civilization-resonance-pressure.md)로 낮춘다. 현장 은어는 도시 냄새다.
- 기록과 정산은 소등 주간에 누가 밝은 구역에 남을지 정하는 행정 절차로 둔다.
- 인간성 등급 지분은 밝은 구역 체류권, 병상권, 성문 통행권, 발전기 시간이 가격화되는 제도로 둔다.
- 마로우와 잔광유는 신드랄에서 정제되는 실제 에너지 자원으로 둔다. 장작은 실제 연료가 아니라 노동 동원, 전력 배제, 병상·거주권 조정, 소등 후순위를 묶는 은어와 배분 문제로 둔다.
- 시민 회복 공공재는 체제를 이기는 해법이 아니라 등불 공유표, 손전등 순번, 명단 벽, 무료 검산대 같은 낮은 마찰로 둔다.
- 죽음의 비즈니스 체인은 괴물 사체에서 나온 마로우와 잔광유, 사람의 죽음이 배분표와 보상 장부로 바뀌는 공급망으로 둔다.

## 공개 문서 원칙

공개 인덱스에는 이 매핑 자체를 노출하지 않는다.
독자는 먼저 [루멘 연방](worlds/lumen-federation.md), [괴물](glossary/monsters.md), [괴물 유인 신호](systems/civilization-resonance-pressure.md), [The Great Dimming](systems/the-great-dimming.md), [루멘 연방 도시 간 의존망](systems/intercity-dependency-network.md), [마로우와 잔광유 연료 체계](systems/marrow-afterglow-fuel-cycle.md), 7개 도시를 읽으면 된다.

깊은 문서는 메인 규칙을 이해한 뒤 읽는 보조 장치다.
제목이 제도명이라도 첫 문단은 반드시 실제 장면, 물건, 도시 기능에서 시작한다.
